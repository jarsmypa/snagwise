## When to use it
Running shoes, running apparel, hydration gear and sports watches.

## Tips
- The previous version of a shoe model is usually discounted when the new one arrives, and changes between versions are often small. Prefer it unless the user needs a specific change.
- Same shoe, different colorway: less popular colors are often the cheapest. Ask the user if color matters.
- Trail shoes and road shoes are not interchangeable: confirm where they run before suggesting.
- Prefer stores with free returns or exchanges for shoes: fit is the main risk when buying online.
- Sports watches: last year's model usually covers what most runners need at a much lower price.

## Red flags
- Prices far below every other store on brand-new releases: possible counterfeits.
- No return policy on footwear.
